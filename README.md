# 🎄 Advent of Code 2016 🎄
This repository is for all of my attempts and solutions for Advent of Code 2016.

Running a specific day:
```bash
julia --project=. run.jl <day>
```

Testing a specific day:
```bash
julia --project=. <day> -t
```
